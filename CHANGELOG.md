# Histórico de versões

## 2.0.0 — Auditoria e estabilização

- Revisão da criação e limpeza de diretórios temporários.
- Diretórios de build criados com permissão restrita no Linux e sem apagar caminhos preexistentes.
- Tratamento de nomes de classes Java inválidos.
- Detecção da declaração `package` após comentários de cabeçalho.
- Verificação da disponibilidade do Git e do repositório antes dos atalhos.
- Correção do comando `:ShowWhitespace`, que agora sempre mostra os caracteres especiais.
- Testes para caminhos com espaços e caracteres especiais.
- Testes Java com pacote, comentário inicial e classe auxiliar.
- Matriz de CI para Vim 8.2+ em Ubuntu 22.04 e 24.04.
- Documentação consolidada de comandos, atalhos, dependências, compatibilidade e segurança.

## 1.4.0

- Testes de configuração e integração.
- Primeira versão do fluxo de CI com matriz Ubuntu.

## 1.3.0

- Navegação, pesquisa de projeto, comentários e modelos de código.

## 1.2.0

## 1.1.1
